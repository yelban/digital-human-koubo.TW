# 敘事手冊：聊天腔外殼，因果鏈核心

來自 97 支字幕的統計與 6 支樣片的逐段拆解。下面的示例句都是原創，只示範手法；不要搬原頻道的句子。

## 文案指標（成品口徑）

| 指標 | 目標 | 說明 |
|---|---|---|
| 語速 | 約 6 字/秒（錄音約 4.8，剪掉氣口後到 6） | align_recording.py 壓停頓後自動接近 |
| 設問 / 反問 | 1–2 次/分鐘 | 拋出後下一句立刻自己回答 |
| 數字 | 3–4 個/分鐘 | 每個關鍵數字配一個參照物：「比 X 一家還多」「是 Y 的 23 倍」 |
| 英文術語 | ≈1 個/分鐘 | 英文原詞 + 一句中文大白話，畫面出術語卡 |
| 開場到「今天聊…」 | 要麼 ≤3 秒直給，要麼 40–60 秒鉤子 | 不要卡在中間 |

## 三種骨架

### A 危機 / 暴雷型（怎麼死的）——銀行倒閉、暴雷、騙局
1. 時間線速覽 + 量級對比（日期貼紙逐個疊上，倒下的劃紅線；先證明「這事很大」）
2. 替觀眾說出質疑：「有人可能覺得…」→ 用資料反駁（stage 柱狀圖）
3. 交接句進入正文（一句話翻開第一章）
4. 主角怎麼起家（客戶是誰、憑什麼做大，順手一個小調侃）
5. 宏觀推力：錢從哪來（三步因果，每步一個數）
6. 「重點來了」：一個當時看起來很合理的錯誤決定（先替對方講清當時為什麼這麼想）
7. 機制解釋：術語卡 + 生活比喻 + 模擬走勢圖；需要時加「硬核預警，跟不上可以跳過」
8. 為什麼沒人發現：會計、監管的盲區；接一句和觀眾錢包有關的話
9. 導火索 + 擬人獨白：把公告翻譯成市場聽到的潛台詞（卡通貼紙 + 氣泡）
10. 高潮：擠兌/暴跌，大數字滾動，一個字或一個詞收尾
11. 支線 + 坦白不確定（「我沒查到直接原因，可能是…也可能是巧合」）
12. 「性質變了」：從個案升級成恐慌；第二人稱假設「要是你的錢存在…你慌不慌」
13. 善後：只有兩條路 + 競猜停頓（「你猜多少錢？」→ 停半秒 → 答案）
14. 復盤：三個原因排主次，其中一個只算「半個」；落到人性（貪婪、僥倖）
15. 展望：「先說答案」+ 一個類比
16. 結尾回扣開頭的私人話題 / 互動提問

### B 收購 / 博弈型（怎麼打的）——惡意收購、董事會之爭、巨頭混戰
1. 冷開場：日期 + 金額大數字（寫滿所有的零）
2. 「最有意思的是 X」：拋出一個核心概念
3. 問題雲：本期要回答的 3–4 個問題，隨後合併成章節標題
4. 給跳轉點：只想聽乾貨的可以跳到 X 分 X 秒
5. 事件經過：每一步配檔案證據卡（標黃關鍵數字）
6. 悖論：「X 不是很厲害嗎，怎麼還是成了？」
7. 虛構小例子講規則（街角奶茶店、小區業委會這種生活化場景）
8. 進攻方的幾招：中英文命名，逐個講，畫面上術語卡橫排成「武器清單」
9. 「精彩的邏輯來了，跟住」：思想實驗，帶具體數字算一遍
10. 防守方的武器：機制、起源、法律依據、經典案例
11. 回到本案：最後為什麼鬆口/成交
12. 武器清單彙總 + 一條原則收尾

### C 悖論型（為什麼反常）——「被卡脖子還能第二」「越加息越漲」
1. 冷開場：反常事實 + 衝擊數字
2. 擺出悖論（兩件看似矛盾的事並列）+ 問題雲
3. 章節一：先把「卡了什麼」講清楚（時間線 + 來回拉鋸，偶爾一句吐槽：「這還是管制嗎？更像收過路費」）
4. 糾偏：「準確地說，不是 X，是 Y」
5. 章節二：「第二」怎麼算的（權威榜單 + 差距變化，主動提到對方的保留意見）
6. 章節三：靠什麼追——編號的幾條，每條一個畫面手法（術語卡 / 下載份額柱圖 / 空鏡比喻 / 梗）
7. 章節四：不好聽的資料（算力份額、投資差距），平衡
8. 一句話總結（毛筆大字）→ 復盤兩面 → 先說答案的展望 → 結尾互動

## 活人感手法（每期至少用 3 個）

| 手法 | 原創示例 | 畫面 |
|---|---|---|
| 開場個人狀態 | 「這週嗓子有點啞，大家將就聽」 | 主播全螢幕，可插自拍 |
| 觀眾點題 | 「後台好多人問同一件事」 | 私信卡左右彈出 |
| 替觀眾說質疑 | 「你可能覺得，倒一家很正常嘛？還真不正常」 | 蓋章大字 |
| 擬人獨白 | 銀行：「我虧錢了…錢不夠了…誰能借我點？」 | 卡通貼紙 + 氣泡逐句 |
| 生活比喻 | 「利率和債價像蹺蹺板」「窮人家的孩子更會過日子」 | 生成的比喻空鏡 |
| 疊詞節奏 | 「買買買」「虧虧虧」 | 大字連跳 |
| 一詞收尾 | 「卒」「過路費？」 | stamp-red |
| 坦白沒查到 | 「後來交付了多少？我查了一圈沒找到靠譜資料」 | 大字 |
| 競猜停頓 | 「你猜多少錢？——一英鎊」 | stage quiz |

| 真實經歷 | 只用主播本人真實經歷；劇本裡留空位讓使用者填，絕不編 | — |

## 語言習慣（節拍詞）

按每 10 分鐘出現次數：其實 11.5、咱/咱們 10.1、你看 6.6、比如說 3.7、你說 3.1、對吧 2.2、你想 1.9、是不是 1.5。

- 「你看」= 要切圖了：說出口的同一幀切到圖表/素材。
- 「其實」= 糾正直覺，後面跟反常識資訊。
- 「咱」= 把觀眾拉到同一邊（北方口語的親近感）。
- 「對吧 / 是不是」= 確認跟上，相當於一個停頓。
- 「你說 / 你想」= 開一個第二人稱假設場景。
- 「當然 / 不過」= 給判斷留餘地，不武斷。

學的是功能，不抄口頭禪本身。給主播設計自己的標誌詞（示例集用「掰開揉碎」代替「一口氣」）和固定結尾。

## 寫拍表時的節奏規則
- 主播全螢幕一次 5–8 秒（新近風格 2–3 秒），觀點和情緒句用全螢幕。
- 一提到具體事物（公司、人、檔案、數字）就切素材或上舞台。
- 圖表一張停 8–10 秒，隨口播逐步揭示（bars 每根一個 cue）。
- 全螢幕拍之間用 punch 1.08–1.15 推近蓋跳切。
- 每 2–3 分鐘一個情緒出口（梗 / 貼紙獨白 / 吐槽大字）。
