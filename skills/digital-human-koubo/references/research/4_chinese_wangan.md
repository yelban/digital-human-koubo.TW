## 共性開場公式

```
[冷開場 3–40 s：無字視覺鉤子 / 發問 + 三連證據 / 情景短劇 / 親歷異常現象]
  → [身份儀式 1–3 s：固定口頭禪或品牌片頭，可以順手塞三連號召]
  → [一句話論點或問題（問句）]
  → [第一個具體數字或案例，2 秒內配上畫面]
```

- 片名出現的時間：半佛 4.0 s，差評約 23.5 s，畢導 40–71 s。內容越「現象驅動」，片名出得越晚。
- 小Lin說是主播開場直接聊加私信卡點題，**網感派先給畫面、後報身份**。數位人做冷開場有個好處：開頭 5–20 秒可以完全不露臉，口型最難的開場段用 B-roll 蓋過去。
- 三家的冷開場都有一條「證據鏈」，由 3 個以上的具體事實組成（差評：銷量、營收、退市、零頭；畢導：綠燈、車流、轉彎），不是一句空泛的斷言。

## 手法清單

### 1. 黑底梗圖窗 + 固定底字幕（半佛式圖文轟炸）
- 長什麼樣：純黑 16:9 畫布，梗圖/動圖居中偏上，寬約 45–47% W、高約 75–80% H，頂邊距約 5% H。梗圖自帶一句梗字：白色粗黑體加黑描邊，壓在圖的上沿或下沿，字高約 7% H；或者用「白底條 + 黑字 + 下面一張圖」的格式。口播字幕獨立固定在 y≈92% 處。梗圖之間硬切，沒有入場動畫。右上角常駐小號白色頻道水印，帶黑描邊。
- 證據：半佛 4EcnJHcZyCo 0:07–0:45（16 張）、2:16.6（白底條格式）、3:34.6（「朋友：…我：」對話格式）；GxNsnH4593E 0:11.5–3:20（約 50 張）。
- 頻率：約 14 張/分鐘（4Ecn 14.2、Gx 14.0 切/分鐘，基本一鏡一圖），單張中位 3.0 s，p10 1.5 s。
- 配合聲音：底下一直鋪 BGM，沒有停頓（靜音段 0–2 處）。切點上的瞬態只比隨機時刻略多（8% 對 2%、4% 對 3%），說明**不是每張圖都配音效**。
- 為什麼有效：每句話都給一個能代入的情緒表情，觀眾不用看懂圖表也能一直看下去。
- 怎麼在 Remotion 裡實現：`<MemeWindow src caption captionPos="top|bottom|header" />` 放在 `<BlackStage>` 裡，拍表一句台詞對應一張圖（`at`）。素材用 AI 生成的原創動物反應圖或 2–4 s 短動圖（Renoise 便宜模型），再加原創吉祥物貼紙。**不要用網路流行梗圖**（貓狗原圖、熊貓頭都有作者版權），換成「同一只原創 IP 動物 × 20 種表情」的素材包。
- 適合：B（直式可以改成上圖下字）、A（做「吐槽段」插段）
- 優先順序：P0

### 2. 冷開場定格 + 片名卡（失敗瞬間 → 去色 → 未完待續）
- 長什麼樣：0–4 s 全螢幕動作片段 → 定格，0.2 s 內去色到灰度 → 左下角出箭頭貼紙（白底黑描邊手寫體）→ 中央深灰半透明圓角框（寬約 66% W，圓角約 16 px，rgba(40,40,40,.7)），白色粗黑體兩行片名，字高約 9% H，下方小字期號 → 2.5 s 後接 0.5 s 雪花噪點轉場。
- 證據：半佛 4EcnJHcZyCo 0:00–0:06.6；GxNsnH4593E 0:00–0:07（多了雪花噪點 6.5–7.0 s）。
- 頻率：每期固定 1 次，是品牌儀式。
- 配合聲音：開頭 0–7 s 只有音樂（whisper 只轉出 [音樂]），定格那一下推測有一個音樂落點。
- 為什麼有效：4 秒內交代清楚題目，期號還能強化「連載」的感覺。
- 怎麼在 Remotion 裡實現：`<ColdOpenFreeze clip freezeAt={4} title={[l1,l2]} vol="VOL.012" arrowText="未完待續" />`，用 CSS `filter: grayscale()` 插值，噪點用 canvas 程式化生成。原版的「To Be Continued」箭頭是 JoJo 動畫的梗，**改成自繪中文箭頭**。動作片段用 AI 生成的原創失敗瞬間。
- 適合：A、B、C
- 優先順序：P0

### 3. 證據截圖飛入：品牌色描邊 + 滑鼠指標 + 數值籤（差評式）
- 長什麼樣：截圖從畫面中心 20% 大小飛入，放大到約 55% W，背景是深灰漸變（#2a2a2a→#1a1a1a）；外面套 4 px 薄荷綠描邊框（實測 #38C878 到 #48F8B8）；右下角跟一個白色滑鼠指標；鏡頭推近關鍵資料點，彈出深藍底白字粗體數值籤（字高約 4% H）。文件常做 3D 透視傾斜（rotateY 約 −20°、rotateX 約 8°），用翻頁或撕紙切到下一張。
- 證據：差評 UGHTnMPZsAM 0:03–0:10（圖表 + 指標 + 「346.8萬台」）、0:16（納斯達克公告透視）、3:31.3（年報截圖）；g00-PGtexNg 1:49.9（新聞頁 + 綠色高亮）、7:18.9（透視文件）。
- 頻率：差評每分鐘約 1–3 張證據截圖，開場 23 秒內就有 4 張。
- 配合聲音：BGM 底子上疊輕微的「嗖」，推測和飛入同步；實測切點瞬態和隨機時刻相當，所以這類音效很輕。
- 為什麼有效：滑鼠指標加描邊，營造出「我剛查到的」第一現場感，可信度比單放截圖高。
- 怎麼在 Remotion 裡實現：`<EvidenceCard src frameColor="#3CF0A0" cursor focus={{x,y,scale}} label="346.8萬台" tilt={-20} />`，用 spring 實現飛入（damping 18），推近用 `interpolate` 驅動 scale 和 translate。素材是自己截的網頁或報告（公開資訊截圖），截圖裡的品牌 Logo 要虛化。小Lin說的 Doc 只有逐行標黃，這裡多了**飛入路徑、品牌色框、指標、透視**。
- 適合：A、C（發布解讀首選）、D
- 優先順序：P0

### 4. 品牌色熒光筆高亮（文件 + 自打字卡都用）
- 長什麼樣：差評用薄荷綠 #38F898 色塊墊在原文句子後面（不透明，蓋住整行高度）；畢導在自己打的題幹卡上，把關鍵短語墊成橙色塊 #E8862A，字保持白色。從左往右擦出，約 0.3 s。
- 證據：差評 g00-PGtexNg 5:50.5（文件綠條 + 圓形主播小窗）、UGHTnMPZsAM 5:09.1；畢導 vwyU2jrc3W4 0:44.6、3:01.5（題幹卡橙塊）。
- 頻率：每期 3–8 處。
- 配合聲音：推測有輕「刷」聲，未實測。
- 為什麼有效：顏色固定成品牌色，觀眾一眼就知道這是重點，同時也在強化品牌。
- 怎麼在 Remotion 裡實現：小Lin說的 Doc 元件加上 `hlColor` 參數，再新增 `<ProblemCard lines hl=[[start,end]] />`，題幹卡左對齊，白色粗體約 6.5% H，疊在暗化的背景畫面上（brightness .55）。
- 適合：A、C、D

## 聲音設計

實測方法：16 kHz 單聲道，10 ms 幀。統計低於 −45 dBFS、持續 0.35 s 以上的靜音段；用 2 kHz 以上的頻譜通量檢測瞬態，看切點前後 ±0.12 s 內有沒有瞬態，再和 2000 個隨機時刻對比。結果：

| 影片 | 靜音段數 | 每秒 10 分位響度中位 | 切點有瞬態 / 隨機時刻 |
|---|---|---|---|
| 半佛 4Ecn | 2（首尾） | −35.8 dBFS | 8% / 2% |
| 半佛 Gx | 0 | −35.1 | 4% / 3% |
| 差評 UGHT | 0 | −33.8 | 10% / 14% |
| 差評 g00 | 2 | −36.0 | 7% / 5% |
| 畢導 vwyU | 3 | −32.6 | 12% / 12% |
| 畢導 DN1J | 6（2:12、10:52 等） | −34.6 | 16% / 17% |

結論：
1. **BGM 墊底從頭鋪到尾**，底噪中位在 −36 到 −33 dBFS，全片幾乎沒有真正的靜音。我們的 BGM 避讓可以壓到口播下方約 −18 dB，但不要關掉。
2. **不是每個切點都配「嗖」**：切點上的瞬態比例和隨機時刻差不多，只有半佛略高（8% 對 2%）。音效只用在事件上（揭示、碎裂、投票、故障插屏），每分鐘 1–3 個就夠，別在每個切點上掛音效。
3. 畢導用**刻意的靜音**做揭示：DN1J 2:12.15 靜音 0.61 s（手電照亮砧板的暗角鏡頭），10:52.8 靜音 1.02 s。可以寫成拍表字段 `"silence": 0.6`，讓 BGM 在揭示前斷開。
4. 半佛開場 0–7 s 只有音樂，沒有口播，冷開場是靠音樂撐的。
5. 我只做了波形統計，沒有逐聲去聽，所以具體是「叮」「啪」還是罐頭笑聲無法確認，以上都標了「推測」。畢導片尾有 BGM 名單卡（vwyU 9:24.9，13 s），說明他每期換好幾首曲子，曲目切換要另外做頻譜分析才能確認。

## 結尾與互動號召

| 頻道 | 號召位置 | 做法 |
|---|---|---|
| 半佛 | 開頭 9 s（貼紙字）+ 結尾最後 2.4 s | 片尾回到鏡子吉祥物，說一句感謝點贊關注，接一句下期再見，沒有總結段。最後一個觀點說完立刻結束 |
| 差評 | 結尾 12 s 口播 | 一鍵三連、評論區互動、關注公眾號、拜託關注，然後接復古顯示器製作名單和台標 sting。短新聞那期（UGHT）完全沒有號召，用一句昇華結束，背景是產品 B-roll 蒙太奇 |
| 畢導 | 中段 2–3 次 0.5 s 故障插屏「點贊關注」+ 結尾口播三連 | 結尾回扣開場短劇，給荒誕場面一個結局（vwyU 用 AI 畫面做了一個誇張收尾），然後是 BGM 名單卡和花絮彩蛋（DN1J 片尾：辦公室花絮畫中畫 + 右側斜體小字備註實際花了多少錢） |

可複用規則：① 號召至少出現兩次，其中一次放在前 15 秒或中段的「揭曉前」；② 片尾用回扣開場的方式收尾（短劇、吉祥物），不要另起一個新話題；③ 花絮彩蛋放在號召之後，獎勵看到最後的人。
