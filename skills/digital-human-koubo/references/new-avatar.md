# 从一张照片做一个新数字人

1. **照片**：一张正脸、光线均匀、头发不挡脸的人物照（数字人照片或自己的生活照都行）。从视频里取帧时挑嘴闭着的一帧。只用本人或明确同意的人的照片。
2. **放进技能**：存到 `assets/`（例如 `assets/my_host.jpg`），不用上传。竖屏照出竖屏口播，横屏照出横屏口播。
3. **四视图（可选）**：用 grok 的 image_edit 拿这张照片出一张四视图，提示词要点：同一个人、同一套衣服发型，四格并排——正面 / 左侧 / 右侧 / 背面，浅灰无缝背景，不出现任何文字。人物要转身、侧脸的片子才需要。
4. **写进 persona.json**：路径填 `grok.reference_image`（第二位主播填 `other_hosts.me.reference_image`），再改 look、voice.desc。
5. **先拍一段**：`build_tasks.py` + `grok_generate.py --only <第 1 段 id>` 拍 8 秒左右，看脸像不像、口型对不对、动作自不自然、声音喜不喜欢，满意了再批量。
