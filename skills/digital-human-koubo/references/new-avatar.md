# 從一張照片做一個新數位人

1. **照片**：一張正臉、光線均勻、頭髮不擋臉的人物照（數位人照片或自己的生活照都行）。從影片裡取幀時挑嘴閉著的一幀。只用本人或明確同意的人的照片。
2. **放進技能**：存到 `assets/`（例如 `assets/my_host.jpg`），不用上傳。直式照出直式口播，橫式照出橫式口播。
3. **四視圖（可選）**：用 grok 的 image_edit 拿這張照片出一張四視圖，提示詞要點：同一個人、同一套衣服髮型，四格並排——正面 / 左側 / 右側 / 背面，淺灰無縫背景，不出現任何文字。人物要轉身、側臉的片子才需要。
4. **寫進 persona.json**：路徑填 `grok.reference_image`（第二位主播填 `other_hosts.me.reference_image`），再改 look、voice.desc。
5. **先拍一段**：`build_tasks.py` + `grok_generate.py --only <第 1 段 id>` 拍 8 秒左右，看臉像不像、口型對不對、動作自不自然、聲音喜不喜歡，滿意了再批次。
