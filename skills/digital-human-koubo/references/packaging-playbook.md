# 包裝手法庫（來自 4 類頂尖創作者逐幀實測）

2026-10 拆了 25 支：英文頂流節奏派（MrBeast / Mark Rober / Ryan Trahan）、科技評測質感派（MKBHD / 影視颶風 / 何同學）、知識解說動畫派（Johnny Harris / Vox / Kurzgesagt / 回形針）、中文口播網感派（半佛仙人 / 差評 / 畢導，對照小Lin說）。完整報告（每條手法都有時間戳證據和參數）在 `references/research/`。這裡是能直接拿來用的結論；每條手法對應的元件見 `references/packaging.md`。

## 1. 節奏：先定目標，再排包裝

| 流派 | 切/分鐘（實測） | 中位鏡頭 | 新視覺事件間隔 | 我們對應的風格 |
|---|---|---|---|---|
| MrBeast | 24–25 | 1.8 秒 | 前 30 秒每 3.3–5 秒一個 | B 直式快節奏、E 冷開場 |
| Mark Rober | 30–50 | 1.0–1.2 秒 | 字跟鼓點 0.3 秒一拍 | B「熱鬧」檔、片頭 |
| Ryan Trahan | 16–17 | 2.9 秒 | 切少但圖形事件多 | B「標準」檔、vlog 口吻 |
| MKBHD | 5.5–6.7 | 約 8 秒 | 畫面幾乎不加字 | C 發布解讀「克制」版 |
| 影視颶風 / 何同學 | 12–17 | 約 3 秒 | 圖形 + B-roll 撐節奏 | C 發布解讀、D 教學 |
| Johnny Harris / Vox | 10–26 / 13 | 3 秒左右 | 前 60 秒最密，正文放慢 | A 解說、D 教學 |
| Kurzgesagt / 回形針 | 4.5–7 / 7–10 | 不硬切，鏡頭內一直在動 | 每 4–5 秒一拍 | A 解說的動畫段 |
| 半佛 / 差評 / 畢導 | 10–17 | 約 3 秒 | 一句話一張圖 | A、B |

**通用規則**
- 切數可以低，**刺激不能斷**：前 30 秒每 3–5 秒要有一個新視覺事件（數字大字、卡片、地圖、轉場、反應、跳切推近）。
- 單機位數位人最便宜的節奏來源是 **PunchInHost**：同一條口播按句子邊界硬切 1.0 / 1.18 / 1.32 倍景別（可左右偏置），不用重新生成。
- 前 60 秒最密，正文可以放慢；長影片每 2–5 分鐘一張章節卡。
- 主播全螢幕一次不超過 12 秒；長段落拆成「全螢幕 → 小窗圖表 → 全螢幕」或「主播 + 身旁懸浮物」。

## 2. 開場公式（30 秒鉤子）

四派歸納成一個能套的模板（括號裡是可用元件）：
```
0–3 秒    命題或動作，不問好、不報名字、不放 Logo（SlamText / NumberSpike / TeaserColdOpen / SearchTyping / ColdOpenFreeze）
3–15 秒   把觀點變成看得見的證據：數字、截圖、小實驗、觀眾自己的搜尋記錄（EvidenceCard / DocFocus / Counter / ReviewCards）
15–30 秒  主問題寫在螢幕上，或者來一句反轉（TiltLine / ChapterCard / WordStack）
22–60 秒  第一張章節卡 = 冷開場結束（ChapterCard / TornStrip）
```
- 英文頂流：2 秒內說出核心名詞 → 0.7–5 秒數字釘子 → 2–12 秒先給結局快閃 → 8–17 秒賭注加碼 → 13–20 秒反應三連 → 25–30 秒進章節。
- 科技評測（中文兩家）：主題句 → 小實驗 → 反轉 → 喊「開始」→ 4–8 秒片頭（音樂比口播響 3–5 LU）。
- 網感派：先給畫面、後報身份；片名出現在 4–70 秒之間，內容越「現象驅動」片名越晚。
- **數位人專用**：開頭 5–20 秒可以完全不露臉（B-roll / 字卡），把口型最難的開場段蓋過去；數位人 3–10 秒內入場，並盡早「指向」證據。

## 3. 字幕和螢幕文字
- 中文直式（B）：保留逐字花字字幕（字號、描邊見 references/huazi.md）。
- 中文橫式解說（A/D）：底部字幕 50–54 px、800 字重、y≈92%，單行 12–18 字，硬切不淡入。
- 發布解讀（C）可以學差評：**不燒錄字幕**，螢幕留給證據卡和數字（平台 CC 字幕兜底）。
- 英文和質感派都不鋪滿字幕：字只給 **數字、關鍵詞、身份 / 時間** 三類資訊。
- 每個資料都掛出處（SourceTag：左下小字 + 紅點，停 3–5 秒）。

## 4. 聲音
- **BGM 床從頭鋪到尾**（中文頭部實測幾乎沒有靜音），人聲出現時壓到約 -18 dB，句間停頓回到 -14 dB。
- **音效只給事件**：揭示、碎裂、投票、數字落定、卡片彈出。中文網感派每分鐘 1–3 個就夠，不要每個切點都掛「嗖」；英文快節奏可以更密（數字落定配低頻 boom）。
- **揭示前刻意靜音 0.6–1.0 秒**（畢導實測），每段末尾留一次 0.4–0.8 秒停頓給笑點或反轉。
- 片頭 / sting 比口播響 3–5 LU，結束前 6 幀淡回。
- 成品響度：直式短影片 -14 LUFS；橫式解說 / 教學 -16 LUFS。

## 5. 號召與結尾
- 號召至少兩次：一次放在前 15 秒或「揭曉前」（PollPop、GlitchInterstitial「點贊關注」0.5 秒），一次在結尾。
- 結尾回扣開場（同一個畫面、同一個問題、同一個角色），不另起新話題；花絮彩蛋放在號召之後。
- 長影片結尾前回到復盤板（RecapBoard）把學到的列一遍。

## 6. 紅線（不照搬）
- **不用網路梗圖、影視劇 / 動畫截圖、明星表情包**：梗圖窗和反應貼紙用原創素材——數位人定妝圖做 20 種表情貼紙、原創 IP 動物表情包（AI 生成），或 Noto 動態表情。
- **不用真實人物照片做名牌**（肖像權）：用無臉剪影 / AI 角色，名牌照常寫，並標「示意角色」。
- **截圖裡的品牌 Logo 虛化**；不仿 Google / 百度等搜尋框品牌（SearchTyping 是中性樣式）。
- **不編資料**：GlassPanel / SpecCard / Counter 裡的數字必須是實測或有出處；示意資料要在畫面上標「示意」。AI 生成的產品鏡頭不能冒充實拍實測。
- 「To Be Continued」箭頭、各家片頭 sting、佈景、口頭禪原句都不照搬，用自繪中文版本。
